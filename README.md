# Kopfrechnen – Rechen-Sprint

Kopfrechen-Trainer für den Unterricht: Einmaleins, Geteilt, Plus und Minus.

**Online:** https://herrkandil.github.io/kopfrechnen/

- Minuten-Sprint (60 Sekunden, Zeit pro Aufgabe passt sich an) und Training ohne Zeitdruck
- Punkte, Level, Rekorde, Urkunde
- Fehleraufgaben werden wiederholt
- Fortschritt bleibt auf dem jeweiligen Gerät gespeichert
